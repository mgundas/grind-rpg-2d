# @jadethrone/data

JSON game data and Tiled maps for Jade Throne. It holds the raw content that the server and client read, the map generator, and (from Phase 3 on) the schemas that validate it.

Planned contents (per `GAME_DESIGN.md`):

- `monsters.json` — monster definitions (starter set in Phase 3)
- `items.json` — item definitions (Phase 4)
- `dropTables.json` — drop tables (Phase 3/4)
- `skills.json` — skills (Phase 6)
- `shops.json` — NPC shop inventories (Phase 4)
- `bonuses.json` — bonus pool for enchant/reinforce scrolls (Phase 7)
- `maps/*.json` — Tiled JSON maps (`map_ember_village`, `map_ember_fields`), generated by `pnpm generate:maps` (`src/generate-maps.ts`); committed because they are deterministic build artifacts
- `jsonSchemas/` — schemas validating all data files; `scripts/validate-data.ts` runs them (Phase 3+)

Balance values only ever live here (AGENTS.md) — stats, prices and drop rates are never hardcoded in game logic. Any data that must be believable in tests is generated with the seeded RNG from `@jadethrone/shared`.
